# ✊ Rock Paper Scissors Game

A simple and interactive **Rock Paper Scissors desktop game** built using Python and Tkinter. Play against the computer, track your score, and be the first to reach 5 points to win the match!

## 🎮 Features

- **User-Friendly Interface** — Clean, pastel-themed graphical interface.
- **Player vs Computer** — Play against the computer with randomly generated moves.
- **Score Tracking** — Displays the player's score, computer's score, and draws.
- **Win Detection** — The first player to reach 5 points wins the match.
- **Instant Results** — Shows the outcome of each round immediately.
- **Restart Option** — Reset the scores and start a new match.
- **Lightweight Application** — Built using Python's built-in Tkinter library.

## 🛠️ Technologies Used

- **Python** — Game logic and application functionality.
- **Tkinter** — Graphical user interface (GUI).
- **Random Module** — Generates the computer's moves.

## 📋 Game Rules

| Player's Move | Computer's Move | Result |
|---|---|---|
| Rock | Scissors | Rock wins |
| Paper | Rock | Paper wins |
| Scissors | Paper | Scissors wins |
| Same move | Same move | Draw |

- Rock beats Scissors.
- Scissors beats Paper.
- Paper beats Rock.
- The same move results in a draw.
- The first to score **5 points** wins the match.

## 🚀 Getting Started

### Prerequisites

- Python 3.x installed on your computer.
- Tkinter (usually included with standard Python installations).

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/raajxvi/rock-paper-scissors.git
```

**2. Navigate to the project directory**

```bash
cd rock-paper-scissors
```

**3. Run the game**

Replace `main.py` with your Python file's actual name if it is different.

```bash
python main.py
```

The game window will open, and you can start playing!

## 🖥️ How to Play

1. Launch the application.
2. Choose **Rock**, **Paper**, or **Scissors**.
3. The computer randomly selects its move.
4. View the round result and updated scoreboard.
5. Continue playing until either the player or computer reaches 5 points.
6. Click **Restart** to play another match.
